Public signed release assets for RigWeave. Source code remains private.

## Public-Launch Baseline V1

The permanent public update compatibility chain begins at:

- Baseline ID: `RW-UPDATE-BASELINE-V1-REV10456`
- Version: `0.5.0-alpha.15`
- Revision: `10456`
- Release tag: `v0.5.0-alpha.15`
- Payload: `RigWeave_v0.5.0-alpha.15_REV10456.zip`
- SHA-256: `8e9d6bd0078fc321e5d2da0acfa50b33c9bbe46b534da90d4bddca8a722f7744`
- Update protocol: `RIGWEAVE-UPDATE-PROTOCOL-V1`

Pre-Rev10456 development/alpha builds are not part of the Public-Launch compatibility guarantee.

From this baseline onward, every supported published RigWeave version must retain a valid direct update path to the current supported release without requiring skipped intermediate application releases.
